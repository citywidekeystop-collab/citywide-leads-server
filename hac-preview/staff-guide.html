Staff user manual

How to evaluate and use the proposed editorial workflow

Scope: this is a manual for the browser-local demonstration, not a production CMS. Do not enter actual confidential records, staff credentials or personal information.

1. Open the workspace

Use Website dashboard in the site footer. The workspace includes homepage editing, page editing, media planning, analytics, this guide, and a launch checklist.

2. Update homepage

  1. Enter a short headline, highlighted line and introduction.
  2. Set the video preference.
  3. Choose Publish to local preview. This updates your browser only; it is not a live-site publish.
  4. Inspect desktop and mobile. Reset demo restores the initial homepage.

3. Edit an existing page

  1. Select a page from the Pages tab, then edit its title and intro.
  2. Choose an existing content section and update title and description. Use clear headings and descriptive text.
  3. Save draft before changing pages. Apply to local preview to inspect the changes. View page opens the selected page.
  4. Verify source links, published dates, role names, and images. Ask the content owner to review factual changes.

Creating pages, server uploads, multi-user review and publishing are not yet supported by the live static preview.

4. Media inventory

Add a planned HTTPS asset location and a descriptive label. This saves a reference only, not an uploaded file. Confirm copyright, image usage rights, meaningful alt text, optimized file sizes and captions or transcripts for meaningful video.

5. Analytics demonstration

Open Analytics demo and explicitly opt in. Visit pages, use search and click resource links. The dashboard records counts in your browser only. Export counters or clear them. Resource clicks do not establish that a download, signup or registration succeeded.

6. Draft backup and reset

Use Launch checklist → Export local draft data to save your current demonstration edits. Clear local content edits resets your browser’s page drafts and content. Keep any exported data private. There is no server backup for this demonstration.

7. Proposed production roles

RoleResponsibility
EditorCreate drafts, validate content and media, submit for review.
Reviewer / publisherApprove, publish and revert revisions; verify accessibility.
AdministratorManage roles, settings, integrations and recovery. Use approved authentication with MFA.

8. Training exercise

Using fictional data only, update a page headline, save a draft, preview the change, verify its mobile layout, and export the result. Repeat with a new page in the future production CMS. Staff acceptance requires completing these exercises without developer assistance.
